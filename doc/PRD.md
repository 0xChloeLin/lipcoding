# 음성녹음 전사 및 다운로드 앱 PRD

## 1. 개요

| 구분 | 내용 |
| --- | --- |
| 서비스 요약 | 사용자가 음성을 녹음하면 Groq 음성 인식 API를 통해 텍스트로 변환하고, 결과를 Excel 또는 TXT 파일로 다운로드할 수 있는 앱 |
| 문제 정의 | 회의, 인터뷰, 강의, 메모 내용을 직접 받아쓰기 어렵고, 녹음 후 정리하는 시간이 오래 걸림 |
| 핵심 가치 | 녹음부터 텍스트 변환, 파일 다운로드까지 한 화면에서 빠르게 처리 |
| MVP 범위 | 1. 음성 녹음 2. Groq 기반 음성 텍스트 변환 3. 전사 결과 조회 및 간단 수정 4. Excel/TXT 다운로드 |
| 제외 범위 | 실시간 협업, 화자 분리, 요약, 번역, 고급 편집기, 결제, 공유 링크, 팀 관리 |

## 2. 목표

### 2-1. 제품 목표

- 사용자가 앱에서 바로 음성을 녹음할 수 있다.
- 녹음된 음성 파일을 Groq API로 전송해 텍스트로 변환할 수 있다.
- 변환된 텍스트를 화면에서 확인하고 간단히 수정할 수 있다.
- 전사 결과를 Excel 또는 TXT 파일로 다운로드할 수 있다.

### 2-2. 성공 기준

| 지표 | 기준 |
| --- | --- |
| 녹음 완료율 | 녹음 시작 사용자 중 80% 이상이 녹음을 정상 저장 |
| 전사 성공률 | 업로드된 녹음 파일 중 95% 이상이 전사 완료 |
| 다운로드 사용률 | 전사 완료 사용자 중 60% 이상이 Excel 또는 TXT 다운로드 사용 |
| 기본 작업 완료 시간 | 5분 음성 기준 녹음 종료 후 1분 이내 전사 결과 제공 |

## 3. 사용자

| 사용자 | 사용 상황 | 필요한 기능 |
| --- | --- | --- |
| 회의 참석자 | 회의 내용을 기록하고 회의록 초안을 만들고 싶음 | 녹음, 전사, Excel/TXT 다운로드 |
| 인터뷰어 | 인터뷰 내용을 텍스트로 정리하고 싶음 | 녹음, 전사 결과 수정, TXT 다운로드 |
| 학생/강의 수강자 | 강의 내용을 기록하고 나중에 복습하고 싶음 | 녹음 목록, 전사 결과 조회, 파일 다운로드 |
| 개인 사용자 | 떠오른 아이디어를 음성으로 남기고 싶음 | 빠른 녹음, 텍스트 변환, TXT 저장 |

## 4. 핵심 기능

### 4-1. 음성 녹음

| 항목 | 요구사항 |
| --- | --- |
| 녹음 시작 | 사용자는 녹음 버튼을 눌러 음성 녹음을 시작할 수 있다. |
| 녹음 중 상태 | 녹음 시간, 일시정지, 재개, 종료 버튼을 표시한다. |
| 녹음 종료 | 사용자가 종료 버튼을 누르면 녹음 파일을 저장한다. |
| 녹음 파일 형식 | 브라우저 또는 앱 환경에서 지원하는 기본 오디오 포맷을 사용한다. |
| 권한 처리 | 마이크 권한이 없으면 권한 요청 안내를 표시한다. |
| 실패 처리 | 녹음 실패 시 사용자에게 오류 메시지와 다시 시도 버튼을 제공한다. |

### 4-2. Groq 음성 전사

| 항목 | 요구사항 |
| --- | --- |
| 전사 요청 | 녹음 완료 후 사용자가 전사하기 버튼을 눌러 Groq API 전사를 요청할 수 있다. |
| 자동 전사 옵션 | MVP에서는 녹음 완료 후 자동 전사를 기본값으로 둘 수 있다. |
| 처리 상태 | 전사 대기, 전사 중, 전사 완료, 전사 실패 상태를 표시한다. |
| 결과 저장 | 전사 결과 텍스트와 녹음 메타데이터를 저장한다. |
| 실패 처리 | API 오류, 파일 용량 초과, 네트워크 오류를 구분해 안내한다. |
| 보안 | Groq API Key는 서버 환경 변수로 관리하고 클라이언트에 노출하지 않는다. |

### 4-3. 전사 결과 조회 및 수정

| 항목 | 요구사항 |
| --- | --- |
| 결과 화면 | 녹음 제목, 생성일, 녹음 길이, 전사 텍스트를 표시한다. |
| 텍스트 수정 | 사용자는 전사 텍스트를 직접 수정하고 저장할 수 있다. |
| 제목 수정 | 사용자는 녹음 제목을 수정할 수 있다. |
| 목록 조회 | 사용자는 이전 녹음 및 전사 결과 목록을 확인할 수 있다. |
| 삭제 | 사용자는 녹음 기록을 삭제할 수 있다. |

### 4-4. 파일 다운로드

| 항목 | 요구사항 |
| --- | --- |
| TXT 다운로드 | 전사 텍스트를 `.txt` 파일로 다운로드할 수 있다. |
| Excel 다운로드 | 전사 결과를 `.xlsx` 파일로 다운로드할 수 있다. |
| Excel 컬럼 | 제목, 녹음일시, 녹음 길이, 전사 내용 컬럼을 포함한다. |
| 파일명 | 기본 파일명은 `recording-{YYYYMMDD-HHmm}` 형식으로 생성한다. |
| 다운로드 범위 | MVP에서는 단일 녹음 결과 다운로드를 우선 지원한다. |

## 5. 화면 설계

| 화면 | 주요 요소 | 설명 |
| --- | --- | --- |
| 홈/녹음 화면 | 녹음 버튼, 녹음 시간, 최근 기록 | 앱 진입 후 바로 녹음을 시작할 수 있는 기본 화면 |
| 녹음 진행 화면 | 타이머, 일시정지, 재개, 종료 | 현재 녹음 상태를 명확히 표시 |
| 전사 처리 화면 | 진행 상태, 로딩 표시, 실패 안내 | Groq 전사 요청 처리 상태 표시 |
| 전사 결과 화면 | 제목, 메타정보, 전사 텍스트 편집 영역, 저장 버튼 | 전사 결과 확인 및 수정 |
| 기록 목록 화면 | 녹음 제목, 날짜, 상태, 상세 이동 | 저장된 녹음 및 전사 결과 목록 |
| 다운로드 영역 | TXT 다운로드 버튼, Excel 다운로드 버튼 | 전사 결과를 파일로 저장 |

## 6. 데이터 설계

### 6-1. 테이블

| 테이블 | 필드 | 설명 |
| --- | --- | --- |
| Recording | id | 녹음 고유 ID |
| Recording | title | 녹음 제목 |
| Recording | audioUrl | 저장된 음성 파일 경로 |
| Recording | durationSec | 녹음 길이(초) |
| Recording | status | `recorded`, `transcribing`, `completed`, `failed` |
| Recording | transcriptText | 전사 결과 텍스트 |
| Recording | errorMessage | 전사 실패 사유 |
| Recording | createdAt | 생성일 |
| Recording | updatedAt | 수정일 |

### 6-2. 상태값

| 상태 | 의미 |
| --- | --- |
| recorded | 녹음 완료, 전사 전 |
| transcribing | Groq API 전사 진행 중 |
| completed | 전사 완료 |
| failed | 전사 실패 |

## 7. 서버 API 요구사항

| API | Method | 설명 |
| --- | --- | --- |
| `/api/recordings` | GET | 녹음 목록 조회 |
| `/api/recordings` | POST | 녹음 메타데이터 및 음성 파일 저장 |
| `/api/recordings/:id` | GET | 녹음 상세 및 전사 결과 조회 |
| `/api/recordings/:id` | PATCH | 제목 또는 전사 텍스트 수정 |
| `/api/recordings/:id` | DELETE | 녹음 기록 삭제 |
| `/api/recordings/:id/transcribe` | POST | Groq API를 사용한 전사 요청 |
| `/api/recordings/:id/download.txt` | GET | TXT 파일 다운로드 |
| `/api/recordings/:id/download.xlsx` | GET | Excel 파일 다운로드 |

## 8. Groq 연동 요구사항

| 항목 | 내용 |
| --- | --- |
| API 용도 | 녹음 파일을 텍스트로 변환 |
| 인증 | 서버 환경 변수 `GROQ_API_KEY` 사용 |
| 호출 위치 | 클라이언트가 아닌 서버에서 호출 |
| 입력 | 사용자가 녹음한 오디오 파일 |
| 출력 | 전사 텍스트 |
| 오류 처리 | API 응답 실패 시 `failed` 상태 저장 및 사용자 안내 |
| 로그 | 요청 성공/실패, 처리 시간, 오류 메시지를 서버 로그로 기록 |

## 9. 비기능 요구사항

| 구분 | 요구사항 |
| --- | --- |
| 보안 | API Key는 클라이언트에 노출하지 않는다. |
| 개인정보 | 음성 파일과 전사 텍스트는 사용자 데이터로 취급한다. |
| 성능 | 일반적인 짧은 녹음은 사용자가 기다릴 수 있는 시간 내에 처리한다. |
| 안정성 | 전사 실패 시 재시도할 수 있어야 한다. |
| 호환성 | 최신 Chrome, Safari, Edge 기준으로 마이크 녹음을 지원한다. |
| 접근성 | 주요 버튼은 명확한 텍스트 라벨을 가진다. |

## 11. 리스크 및 대응
